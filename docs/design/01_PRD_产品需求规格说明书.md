# PRD：产品需求规格说明书

- **项目名称**：OB Code Preview（Obsidian 代码文件预览插件）
- **文档类型**：PRD
- **版本**：v1.0
- **日期**：2026-08-04
- **作者**：项目负责人

---

## 1. 项目概述

OB Code Preview 是一个 Obsidian 社区插件，让用户能在 Obsidian 中**直接查看代码文件**（如 `.sh`、`.py`、`.yaml` 等）。代码文件在编辑器中像 Markdown 一样打开，内容以代码块形式渲染并做语法高亮，实现"看代码文件就像看 md 文件一样"的体验。

## 2. 目标用户

- **Obsidian 用户**，尤其是需要在内置知识库中浏览代码文件的用户。

## 3. 核心功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| FR-1 | 文件类型接管 | 插件接管指定扩展名的文件，在 Obsidian 中打开时以代码视图渲染 |
| FR-2 | 常见类型预置 | 默认支持以下扩展名：`.sh`、`.py`、`.yaml`、`.yml`、`.ini`、`.conf` |
| FR-3 | 可配置扩展名 | 用户在插件设置中可增删被接管的扩展名列表，其余类型由用户自行配置 |
| FR-4 | 语法高亮 | 内容按对应语言语法高亮渲染 |
| FR-5 | 只读查看 | 仅展示代码，不提供编辑与运行能力 |

## 4. 用户故事与验收标准

### US-1 查看代码文件

> 作为 Obsidian 用户，我想点击一个 `.py` 文件直接看到高亮后的代码，而不是看到纯文本或系统默认编辑器。

**验收标准：**
- 在文件列表中点击 `.py` 文件，编辑区显示语法高亮的代码内容。
- 其余预置类型（`.sh`、`.yaml`、`.yml`、`.ini`、`.conf`）同样以代码视图打开。

### US-2 配置自定义类型

> 作为用户，我想让插件也支持我自己的配置文件类型（如 `.toml`）。

**验收标准：**
- 在插件设置中添加 `.toml` 后，点击 `.toml` 文件能以代码视图打开。
- 移除某个扩展名后，该类型文件恢复为 Obsidian 默认行为。

### US-3 只读保护

> 作为用户，我不想误编辑代码文件。

**验收标准：**
- 代码视图为只读，无法修改文件内容。

## 5. 明确不做（Out of Scope）

- ❌ 不提供代码**编辑**功能
- ❌ 不提供代码**运行**/执行功能
- ❌ 不提供代码**搜索**、折叠等编辑器增强
- ❌ 不做超大文件的性能优化（如几十 MB 级别）

## 6. 非功能需求

- 遵循 Obsidian 插件规范（manifest.json），支持手动安装，符合社区插件分发要求。
- 渲染性能满足常规代码文件规模即可，不针对超大文件做专门优化。
- 设置项仅包含扩展名列表，不提供自定义高亮主题等其他配置。

## 7. 设置项

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 接管文件扩展名 | 字符串列表 | `.sh`、`.py`、`.yaml`、`.yml`、`.ini`、`.conf` | 被插件以代码视图接管的扩展名，可增删 |
